# Original project artwork

`demo_reference.png` is original procedural artwork generated for Lunar HDR
Studio by `lunarhdr/publicdemo.py` with size 1000 and seed 271828. Its pixels come
from mathematical fields, generated noise, invented crater and basin positions,
and built-in OpenCV lettering. No photograph, external image, user file, or
observational dataset contributes to this asset.

The image is visibly labeled **SYNTHETIC DEMO**. It is a lunar-style test pattern,
not a photograph, an accurate lunar map, or real mineralogical information. The
application derives synthetic exposure brackets from this pattern to demonstrate
registration and image controls.

Regenerate it from the project root:

```sh
python -m lunarhdr.publicdemo
```

`icon.svg` is original project vector artwork composed of simple geometric
shapes. `icon.icns` is its rasterized application-icon counterpart. These assets
are original project material covered by the MIT license at the repository root.
Dependency license texts under `licenses/` retain their respective upstream
licenses. Photographic documentation examples have separate provenance in
`docs/IMAGES.md` and are not bundled as application demo assets.
